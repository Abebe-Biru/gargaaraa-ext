# Gargaaraa AI Assistant 🇪🇹

### *Your Intelligent Bridge to the Web.*

![Version](https://img.shields.io/badge/version-1.4-blue) ![Manifest](https://img.shields.io/badge/manifest-V3-green) ![License](https://img.shields.io/badge/license-MIT-lightgrey)

**Gargaaraa** is your AI companion for the web, fluent in **Afaan Oromoo** and **Amharic**. Chat with websites, documents, and text instantly.

## 🛠️ How to Install

1.  **Download** the `Gargaaraa-Extension` folder to your computer.
2.  Open Google Chrome and type `chrome://extensions` in the address bar.
3.  Toggle **Developer mode** (top right corner) to **ON**.
4.  Click **Load unpacked** (top left).
5.  Select the `Gargaaraa-Extension` folder.
6.  📌 **Pin** Gargaaraa to your toolbar for easy access.

## 🚀 Getting Started

### 1. Setup
*   Click the Gargaaraa icon to open the side panel.
*   Click **⚙️ Settings** (top right).
*   Enter your **Addis Assistant API Key**.
*   Choose your language (**Afaan Oromoo** or **Amharic**) and click **Save**.

### 2. Three Ways to Use
*   **🌍 Chat with Page:** Click the **Globe Icon** in the chat bar to read and summarize the current webpage.
*   **🖱️ Select & Chat:** Highlight any text on a website → Click the **Gargaaraa Icon** that pops up (or Right-Click > "Chat with Gargaaraa").
*   **📄 Analyze Files:** Click the **Paperclip 📎** to upload PDF or TXT files and ask questions about them.
